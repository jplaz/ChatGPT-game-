# A Song of Ice and Monsters — Delta GBA branch

Separate Game Boy Advance / Delta homebrew build. This branch does not replace the browser game on `main`.

The build uses original code/art with Gen III-era map, sprite, battle, and UI conventions adapted to Westeros content.

Controls: D-pad move; A interact/confirm; B quick battle/cancel; START menu.

Current playable ROM vertical slice includes a title screen, Winterfell overworld, NPC interaction, battle screen, menu, and a defeated Bolton raider that remains gone for the current session.
